# CIRCULGIFT — демо-проект

Это статический прототип интерфейса CIRCULGIFT. Он запускается прямо на GitHub Pages и не требует сборки.

## Что внутри
- Главная страница в чёрно-синей / электрически-голубой стилистике.
- Чертёжный циркуль как центральный графический символ (не компас).
- Демо-режимы Draw Wheel, Rocket, Neon Slots и High/Low.
- Виртуальный баланс CG, ежедневный бонус, демонстрационный каталог подарков и инвентарь.
- Профиль и пример реферальной ссылки.

## Как загрузить в GitHub
1. Открой репозиторий `CIRCUL_GTA6`.
2. Нажми **Add file → Upload files**.
3. Распакуй архив на компьютере и перетащи `index.html`, `style.css`, `app.js`, `README.md` в корень репозитория.
4. Нажми **Commit changes**.
5. Если GitHub Pages уже включён для ветки `main` и папки `/ (root)`, сайт обновится автоматически. Иначе открой **Settings → Pages** и выбери `Deploy from a branch` → `main` → `/ (root)`.

## Важно
Это только фронтенд-демо. Баланс и игры работают локально в браузере и не синхронизируются между игроками. Нет сервера, аккаунтов, Telegram-авторизации, реального мультиплеера, TON-платежей или вывода денег. Не используй реальные деньги в этой версии. Для настоящей платформы понадобятся backend, база данных, защита от подмены результатов, аудит безопасности и отдельная юридическая проверка.
