# CIRCULGIFT ULTRA

Обновлённый статический демо-фронтенд для GitHub Pages.

## Установка
1. Открой репозиторий GitHub `CirculGames`.
2. Зайди в корень ветки `main`.
3. Замени файлы `index.html`, `style.css`, `app.js` новыми файлами из архива.
4. Нажми Commit changes и подожди публикации GitHub Pages.

Не загружай архив ZIP как единственный файл сайта — сначала распакуй его. Файлы должны лежать в корне репозитория рядом друг с другом.

## Важно
Это клиентское демо. CG — виртуальные очки без денежной стоимости. Результаты игр локальные и случайные; серверной проверки, аккаунтов, мультиплеера и платежей нет.
